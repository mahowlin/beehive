# /refresh - Mid-Session Plan Hygiene

Use when your context window is filling up, your plan feels stale, or you want to checkpoint progress.

Perform these steps:

1. **Re-read your plan file**

2. **Update Tasks**
   - Check off completed tasks
   - Remove irrelevant tasks
   - Add discovered sub-tasks

3. **Update Technical Context**
   - Remove outdated assumptions
   - Add new learnings (files discovered, patterns identified)

4. **Update Session State**
   - Set Last Updated timestamp
   - Set Current Task
   - Set Next Step
   - Add Context Notes (key decisions, gotchas)

5. **Update Risks / Open Questions**
   - Add newly discovered risks
   - Remove resolved questions

6. **Verify Done Criteria** — Still accurate? If criteria need changes, flag to Queen (don't edit them yourself).

7. **Confirm** — Tell the user what changed in the plan

## Permitted Edits

- Tasks (checkboxes, add/remove)
- Session State
- Technical Context
- Risks / Open Questions
- Completion Summary

## Never Edit During /refresh

- Objective
- Why This Approach
- Implementation Strategy
- Done Criteria

If these sections need changes, flag to Queen via `/report`.
